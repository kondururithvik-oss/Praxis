Superposition Theorem Trainer Kit
Basic Electrical Engineering Lab

Aim

To verify the Superposition Theorem experimentally for a linear, bilateral electrical network containing multiple independent DC voltage sources.

Specifically, to show that the load current flowing in the middle branch containing resistor R3 (47Ω) when both voltage sources ($V_1$ and $V_2$) are active simultaneously is equal to the algebraic sum of the individual load currents flowing when each source acts alone, with all other independent sources replaced by their internal resistances (short-circuited).

Experimental Procedure

  1. Switch ON the main trainer board power toggle switch (bottom right).
  2. Step 1: Connect Input V1
    • Connect Variable supply + (term_vvar1) to A (term_sup_a) using a red wire.
    • Connect Gnd (term_gnd1) to B (term_sup_b) using a black wire.
  3. Step 2: Insert the Ammeter in Series
    • Connect Node AM_A (term_sup_ama) to Ammeter + (term_ipos).
    • Connect Node AM_F (term_sup_amf) to Ammeter - (term_ineg).
  4. Step 3: Connect the Voltmeter
    • Connect Node E (term_sup_e) to Voltmeter + (term_vpos).
    • Connect Node B (term_sup_b) to Voltmeter - (term_vneg).
  5. Step 4: Wire the states to verify superposition
    • Both Active: Apply +15V Fixed to C (term_sup_c) and Gnd to D (term_sup_d). Slide the Variable Voltage V1 control in the sidebar. Click Add Row to record values.
    • V1 Only: Short C to D using a yellow jumper. Record the load current as $I_1$ on the ammeter.
    • V2 Only: Short A to B using a yellow jumper. Connect +15V Fixed to C and Gnd to D. Record the load current as $I_2$ on the ammeter.
  6. Check that the total current is the algebraic sum: $I_3 = I_1 + I_2$.

Result

The Superposition Theorem has been successfully verified experimentally for a linear, bilateral DC network.

It was observed that the load current in the middle load resistor branch when both voltage sources are active simultaneously is equivalent to the sum of the load currents when each source acts alone:

I3 = I1 + I2

The experimental values logged inside the observation table match the theoretical calculations solved using Nodal Analysis and Mesh Loop equations within less than 0.01% error, validating the linearity and bilateral nature of the network components.
